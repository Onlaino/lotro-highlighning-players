# Security policy

Only the latest published version of Enemy Highlight receives security fixes.
Before reporting a problem, reproduce it with that version when possible.

Do not post private player notes, PluginData, account information, or an
unpatched exploit in a public issue. Use GitHub's private vulnerability report
for this repository when it is available. If private reporting is unavailable,
open a minimal issue asking the maintainer for a private contact channel and do
not include sensitive details.

Ordinary Lua errors, UI defects, and feature requests can use the public issue
templates. Include the plugin version and reproduction steps, but replace real
character names and notes with test data.
