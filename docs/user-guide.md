# Руководство пользователя Enemy Highlight

**Русский** | [English](user-guide.en.md) · [К документации](README.md)

## Назначение плагина

Enemy Highlight хранит созданные вами записи о персонажах LOTRO. У каждой
записи есть имя, цветная метка и необязательная заметка. Когда сохранённый
персонаж выбран целью, рядом со штатной рамкой цели появляется назначенная
метка.

Плагин ничего не сканирует и не классифицирует автоматически. Метки — личные
пользовательские отметки.

## Установка и обновление

1. Скачайте `Enemy-Highlight-vX.Y.Z.zip` из блока `Assets` нужного
   [GitHub Release](https://github.com/Onlaino/lotro-highlighning-players/releases).
   Не используйте автоматически созданный архив `Source code`.
2. Распакуйте архив в
   `Documents\The Lord of the Rings Online\Plugins`.
3. Проверьте путь к манифесту:
   `Documents\The Lord of the Rings Online\Plugins\HighlightPlayers\HighlightPlayers.plugin`.
4. В игре выполните `/plugins refresh`.
5. Откройте менеджер плагинов LOTRO и загрузите `Enemy Highlight`.

Для обновления замените файлы каталога `HighlightPlayers` и перезагрузите
плагин. Не удаляйте PluginData: старый формат обновляется автоматически.

После успешной загрузки в чате появляется сообщение с текущей версией. Если
плагин не появился в менеджере, в первую очередь проверьте, что архив не создал
лишний вложенный каталог `HighlightPlayers\HighlightPlayers`.

## Быстрый старт

1. Выполните `/eh` или нажмите плавающую кнопку.
2. Введите имя персонажа или выберите его целью и нажмите `Use target`.
3. Выберите метку и нажмите `Add / update`.
4. При необходимости нажмите имя в списке и добавьте заметку в карточке.
5. Снова выберите этого персонажа целью: рядом с рамкой цели появится метка.

## Главное окно

В верхней части окна находятся поле `Player name`, кнопка `Use target`, список
меток, кнопка `Add / update` и переход в `Manage labels`.

Слева показаны категории меток со счётчиками. Категория `All` содержит всю
базу. Нажатие на конкретную метку фильтрует список и выбирает эту метку для
новой записи; выбор `All` не меняет текущую метку формы.

Поле `Search` ищет по части имени без учёта регистра для обычных латинских
имён. В `All` поиск выполняется по всей базе, в категории — только внутри неё.
Заметки в поиск не входят. Нажатие на имя открывает карточку, где можно изменить
имя, метку, заметку или удалить запись.

## Управление метками

Откройте окно кнопкой `Manage labels` или командой `/eh labels`. В нём можно:

- создать, переименовать и перекрасить метку;
- задать компоненты RGB от `0` до `255`;
- увидеть число назначенных игроков;
- удалить неиспользуемую метку;
- настроить максимальные ширину и высоту индикатора.

Имя метки обязательно, не длиннее 32 символов и должно быть уникальным без
учёта регистра. Последнюю метку удалить нельзя. Метку с назначенными игроками
можно удалить только после переноса или удаления этих записей.

## Индикатор цели

Индикатор появляется только для известной цели. Его размер зависит от названия
метки и ограничен настройками из `Manage labels`.

Чтобы изменить положение:

1. выполните `/eh move`;
2. перетащите индикатор с пометкой `[drag]` левой кнопкой мыши;
3. выполните `/eh lock`.

После блокировки индикатор не перехватывает клики по игровому интерфейсу.
Позиция и ограничения размера сохраняются автоматически.

## Плавающая кнопка

Плавающая кнопка всегда доступна независимо от текущей цели. Короткий клик
открывает или скрывает главное окно. Чтобы переместить кнопку, удерживайте
левую кнопку мыши и перетащите её. Позиция сохраняется после отпускания.

## Команды чата

| Команда | Действие |
|---|---|
| `/eh`, `/eh toggle` | Открыть или скрыть главное окно |
| `/eh show` | Открыть главное окно |
| `/eh hide` | Скрыть главное окно |
| `/eh move` | Показать и разблокировать индикатор |
| `/eh lock` | Зафиксировать индикатор и пропускать клики |
| `/eh labels` | Открыть управление метками |
| `/eh add <nickname>` | Открыть карточку с заполненным именем |
| `/eh add <nickname> <label name>` | Сразу назначить указанную метку |
| `/eh info <nickname>` | Вывести сохранённую заметку в чат |
| `/eh probe` | Вывести диагностику текущей цели |
| `/eh help` | Показать краткую справку |

Название метки в `/eh add` может содержать пробелы. Повторное добавление имени
меняет метку, но сохраняет заметку.

## Имена и сопоставление цели

Перед сохранением имя очищается от пробелов по краям и приводится к нижнему
регистру через `string.lower`. Поэтому `Antwyn`, `ANTWYN` и `antwyn` используют
один ключ. Сопоставление цели точное после такой нормализации, а поиск в списке
поддерживает частичное совпадение.

В LOTRO Lua нет полноценной Unicode-нормализации, поэтому сравнение без учёта
регистра гарантировано прежде всего для обычных латинских имён. NPC с тем же
именем технически неотличим от сохранённого игрока.

## Хранение данных

Метки, записи, заметки, положения окон и настройки сохраняются через LOTRO
PluginData в области текущего сервера. Персонажи одной учётной записи на одном
сервере используют общую базу; данные разных серверов не смешиваются.

Перед ручными экспериментами или установкой тестовой версии рекомендуется
сделать резервную копию PluginData. Обычное обновление плагина не требует
удаления сохранённых данных.

## Если что-то не работает

### Плагин не виден в менеджере

- проверьте путь к `HighlightPlayers.plugin`;
- выполните `/plugins refresh` после распаковки;
- убедитесь, что скачали архив из `Assets`, а не исходный код релиза.

### Метка не появляется у цели

- проверьте, что имя сохранено без опечатки;
- выполните `/eh probe` и сравните имя цели с записью;
- убедитесь, что выбрана именно сохранённая цель, а не NPC с похожим именем.

### Окно или индикатор мешает интерфейсу

- переместите индикатор через `/eh move`, затем выполните `/eh lock`;
- перетащите плавающую кнопку удержанием левой кнопки мыши;
- измените пределы индикатора в `Manage labels`.

При создании отчёта об ошибке укажите версию плагина, сервер, последовательность
действий и полный текст Lua-ошибки.
