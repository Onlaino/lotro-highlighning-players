# Результат проверки API выбранной цели

Технический прототип проверен в актуальном обычном клиенте LOTRO.

Подтверждено:

- `LocalPlayer:GetTarget()` возвращает выбранную цель;
- событие `LocalPlayer.TargetChanged` срабатывает при смене цели;
- `GetName()` возвращает имя цели;
- после снятия цели возвращается `nil`.

Примеры фактического вывода:

```text
[HighlightPlayers] Target: Antwyn | type=Actor | alignment=unavailable | local=false | reason=TargetChanged
[HighlightPlayers] Target: Coldfells Elite | type=Actor | alignment=unavailable | local=false | reason=TargetChanged
```

Ограничение: обе цели предоставлены как `Actor`. `GetAlignment()` определён для
`Player`, но отсутствует у `Actor`, поэтому плагин не может надёжно определить,
является выбранная цель Свободным народом или Игроком-монстром. Также тип
`Actor` нельзя использовать как надёжный способ отличить PvMP-игрока от NPC.

Принятое решение: основная логика использует только имя выбранной цели и ищет
его в списке, который пользователь заполняет вручную. База отношений общая для
обеих сторон, поэтому сторона цели для отображения статуса не требуется.
