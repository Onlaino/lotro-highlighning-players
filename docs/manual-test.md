# Ручная проверка Enemy Highlight

## 1. Загрузка и миграция

1. Сохранить резервную копию существующего PluginData.
2. Установить каталог `HighlightPlayers` по инструкции из `README.md`.
3. Выполнить `/plugins refresh` и загрузить `Enemy Highlight`.
4. Убедиться, что нет Lua-ошибок.
5. Для базы v1 проверить сохранность `Friend`, `Neutral`, `Enemy`, игроков и
   заметок после миграции.
6. Перезагрузить плагин: дубликаты меток не должны появиться.

## 2. Главное окно

1. Выполнить `/eh`, `/eh hide`, `/eh show`.
2. Проверить список меток слева и счётчики игроков.
3. Переместить окно и проверить восстановление позиции после перезагрузки.

## 3. Управление метками

1. Открыть `Manage labels` кнопкой и `/eh labels`.
2. Проверить стандартные `Friend`, `Neutral`, `Enemy`.
3. Создать `Raid target` с пользовательским RGB-цветом.
4. Проверить появление метки во всех селекторах без перезагрузки.
5. Переименовать её в `Priority target` и изменить цвет.
6. Попытаться создать дубликат имени в другом регистре.
7. Проверить пустое/длинное имя и неверные RGB-значения.
8. Удалить неиспользуемую метку.
9. Убедиться, что последнюю метку удалить нельзя.

## 4. Записи игроков

1. Добавить игроков с разными стандартными и пользовательскими метками.
2. Повторно добавить имя в другом регистре с другой меткой: дубликата быть не
   должно.
3. В карточке изменить имя, метку и многострочную заметку.
4. Попытаться удалить используемую метку: операция должна быть заблокирована.
5. Перенести игрока и удалить освободившуюся метку.
6. Удалить запись игрока.

## 5. Поиск

1. Добавить похожие имена в разные категории.
2. Проверить частичный поиск без учёта регистра.
3. Проверить отдельный запрос каждой категории и кнопку `Clear`.

## 6. Цель и индикатор

1. Выбрать игрока, нажать `Use target` и назначить метку.
2. Проверить имя и цвет метки на индикаторе.
3. Переименовать и перекрасить назначенную метку: индикатор должен обновиться.
4. Выбрать неизвестную цель или снять цель: индикатор должен исчезнуть.
5. Удалить запись текущей цели: индикатор должен исчезнуть сразу.

## 7. Положение и размер

1. Выполнить `/eh move`, перетащить `MOVE`, затем `/eh lock`.
2. Проверить, что заблокированный индикатор не перехватывает клики.
3. В `Manage labels` применить `60 x 20`, промежуточный и `300 x 80`.
4. Проверить нечисловые и выходящие за пределы значения.
5. Установить удобный размер и проверить восстановление после перезагрузки.

## 8. Команды

```text
/eh labels
/eh add Testname
/eh add Testname Friend
/eh add Testname Priority target
/eh add Testname Unknown label
/eh info Testname
/eh info TESTNAME
/eh info Unknownname
/eh probe
/eh help
/eh unknown
```

Смена метки не должна удалять заметку. Многословная метка должна находиться
целиком. Ошибочные команды должны давать понятное сообщение без Lua-ошибки.

## 9. Производительность

1. Проверить быстрые смены цели без зависаний.
2. Проверить поиск и категории с 100 записями.
3. По возможности повторить с 500 и 1000 записями.
4. При закрытых окнах и неизменной цели не должно быть периодических задержек.
5. После мутаций счётчики и списки должны обновляться без устаревших данных.

## 10. Сохранение и стороны

1. Перезагрузить плагин и проверить метки, цвета, записи и заметки.
2. Проверить общую базу другим персонажем того же сервера.
3. По возможности проверить Свободные народы и Игрока-монстра.
4. На другом сервере должна использоваться отдельная база.
