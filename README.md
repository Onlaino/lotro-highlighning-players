# Enemy Highlight

`Enemy Highlight` — плагин для The Lord of the Rings Online, который позволяет
вручную запоминать персонажей как `Friend`, `Neutral` или `Enemy`. Когда
сохранённый персонаж выбран целью, рядом со штатной рамкой цели появляется
цветная метка с его статусом.

Каталог и Lua-пространство имён плагина называются `HighlightPlayers`.

## Что умеет плагин

- хранит отдельные списки `Friend`, `Neutral` и `Enemy`;
- показывает зелёную, оранжевую или красную статусную метку выбранной цели;
- позволяет перемещать метку и фиксировать её в удобном месте;
- добавляет и обновляет игроков через окно или команды чата;
- подставляет имя текущей цели в форму добавления;
- предоставляет карточку игрока с именем, статусом и многострочной заметкой;
- фильтрует каждую вкладку по части имени без учёта регистра;
- сохраняет базу и позиции окон средствами штатного LOTRO PluginData;
- использует одну базу для персонажей одного сервера и разные базы для разных
  серверов.

## Установка и обновление

1. Скопировать каталог `HighlightPlayers` целиком в:
   `Documents\The Lord of the Rings Online\Plugins`.
2. Проверить итоговый путь к манифесту:
   `Documents\The Lord of the Rings Online\Plugins\HighlightPlayers\HighlightPlayers.plugin`.
3. В игре выполнить `/plugins refresh`.
4. Открыть менеджер плагинов LOTRO и загрузить `Enemy Highlight`.

При обновлении нужно заменить файлы внутри установленного каталога
`HighlightPlayers`, а затем перезагрузить плагин. Удалять PluginData не нужно.

После успешной загрузки в чате появляется сообщение:

```text
[HighlightPlayers] Enemy Highlight v0.1.0 loaded. Use /eh to open.
```

## Как это работает

1. Пользователь вручную добавляет имя и выбирает отношение.
2. Плагин сохраняет нормализованный ключ имени и отображаемое написание.
3. При событии смены цели плагин получает её имя через LOTRO Lua API.
4. Имя цели нормализуется и ищется в сохранённой базе.
5. При совпадении показывается метка `FRIEND`, `NEUTRAL` или `ENEMY`.
6. Для неизвестной или снятой цели метка скрывается.

Плагин ничего не добавляет и не классифицирует автоматически. Назначенный
статус — личная пользовательская отметка, а не сторона персонажа, полученная
из игры.

### Сравнение имён

Перед сохранением и сравнением имя:

1. преобразуется в строку;
2. очищается от пробелов по краям;
3. приводится к нижнему регистру через `string.lower`.

Таким образом, `Antwyn`, `ANTWYN` и `antwyn` используют один ключ `antwyn`.
Сравнение выбранной цели с базой точное после нормализации. Поиск в списках,
напротив, использует частичное совпадение: запрос `ant` найдёт `Antwyn`.

Lua-клиент LOTRO не предоставляет полноценную Unicode-нормализацию, поэтому
гарантированное сравнение без учёта регистра относится прежде всего к обычным
латинским именам.

## Главное окно

Открыть или скрыть окно можно командой `/eh`. В верхней части находятся:

- поле `Player name`;
- кнопка `Use target`, подставляющая имя выбранной цели;
- выбор `Friend / Neutral / Enemy`;
- кнопка `Add / update`.

Сохранённые записи распределены по трём вкладкам. Счётчик на вкладке показывает
общее число игроков с соответствующим статусом. Нажатие на имя открывает
карточку, где можно изменить имя, статус и заметку либо удалить запись.

Поле `Search` фильтрует активную вкладку во время ввода. Для каждой вкладки
используется отдельная строка поиска до перезагрузки плагина. Кнопка `Clear`
очищает фильтр активной вкладки.

## Статусная метка

Цвета метки:

- `FRIEND` — зелёный;
- `NEUTRAL` — оранжевый;
- `ENEMY` — красный.

Чтобы изменить её положение:

1. выполнить `/eh move`;
2. зажать появившуюся метку `MOVE` левой кнопкой мыши;
3. перетащить её к штатной рамке цели;
4. выполнить `/eh lock`.

Положение сохраняется автоматически. После `/eh lock` метка не перехватывает
клики по игровому интерфейсу. В режиме перемещения известной цели на ней
отображается, например, `MOVE / ENEMY`.

## Команды

- `/eh` или `/eh toggle` — открыть или скрыть главное окно;
- `/eh show` — открыть главное окно;
- `/eh hide` — скрыть главное окно;
- `/eh move` — показать и разблокировать статусную метку;
- `/eh lock` — зафиксировать метку и пропускать через неё клики;
- `/eh add <nickname>` — открыть карточку добавления с заполненным именем;
- `/eh add <nickname> friend` — сразу сохранить игрока как друга;
- `/eh add <nickname> neutral` — сразу сохранить нейтральный статус;
- `/eh add <nickname> enemy` — сразу сохранить игрока как врага;
- `/eh info <nickname>` — вывести в чат сохранённую заметку об игроке;
- `/eh probe` — вывести диагностику выбранной цели;
- `/eh help` — вывести краткую справку по командам.

Быстрое повторное добавление существующего имени меняет его статус, но не
удаляет ранее сохранённую заметку. Команда `info` ищет имя без учёта регистра;
например, `/eh info ANTWYN` найдёт сохранённую запись `Antwyn`.

## Хранение данных

Данные загружаются и сохраняются через `Turbine.PluginData.Load` и
`Turbine.PluginData.Save` с областью `Turbine.DataScope.Server` и ключом
`HighlightPlayers`.

Хранятся:

- отображаемое и нормализованное имя;
- статус;
- заметка;
- позиции главного окна, карточки и статусной метки;
- состояние блокировки метки;
- версия формата данных.

База общая для персонажей пользователя на текущем сервере, включая Свободные
народы и Игроков-монстров. Между серверами данные не смешиваются. Файлы внутри
каталога самого плагина при сохранении не изменяются.

## Ограничения LOTRO Lua API

`GetTarget()` и `TargetChanged` позволяют получить смену цели и её имя. Однако
PvMP-персонаж может возвращаться клиентом только как `Actor`, у которого нет
`GetAlignment()`. Поэтому плагин не пытается автоматически определять, является
цель Свободным народом или Игроком-монстром.

Записи сопоставляются только по имени. NPC с таким же именем технически
неотличим от сохранённого игрока, но плагин никогда не добавляет NPC или игроков
самостоятельно.

## Структура проекта

- `HighlightPlayers/HighlightPlayers.plugin` — манифест LOTRO;
- `HighlightPlayers/Main.lua` и `App.lua` — запуск и жизненный цикл;
- `Storage.lua` и `Relationships.lua` — PluginData и база отношений;
- `TargetTracker.lua` и `Indicator.lua` — отслеживание цели и метка;
- `MainWindow.lua` и `PlayerCardWindow.lua` — пользовательский интерфейс;
- `Commands.lua` — команды `/eh`;
- `docs/manual-test.md` — сценарий ручной проверки в клиенте LOTRO;
- `docs/prototype-test.md` — результат исследования API выбранной цели.

## Разработка и проверка

Для работы плагина сторонние Lua-библиотеки не требуются. Синтаксис исходников
можно проверять любым Lua 5.1-совместимым парсером, но окончательная проверка
интерфейса, событий цели и PluginData выполняется внутри клиента LOTRO.

Сценарий проверки: [docs/manual-test.md](docs/manual-test.md).
Результат исследования цели: [docs/prototype-test.md](docs/prototype-test.md).
Инструкция по выпуску релизов: [docs/releasing.md](docs/releasing.md).
