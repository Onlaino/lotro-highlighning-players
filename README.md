# Enemy Highlight

**Русский** | [English](README.en.md)

`Enemy Highlight` — плагин для The Lord of the Rings Online, который помогает
вести личную базу персонажей. Назначайте игрокам цветные метки и заметки, а
плагин покажет сохранённую метку рядом со штатной рамкой выбранной цели.

> Плагин не сканирует окружающих персонажей и не определяет сторону игрока
> автоматически. Все записи создаёт сам пользователь.

## Возможности

- произвольные метки с настраиваемыми названиями и RGB-цветами;
- заметки и поиск по сохранённым персонажам;
- индикатор метки с tooltip и быстрым редактированием заметки текущей цели;
- добавление игроков через интерфейс и команды `/eh`;
- общая база для персонажей одного сервера и отдельные базы для разных
  серверов;
- автоматическая миграция данных при обновлении формата.

## Установка

1. Скачайте `Enemy-Highlight-vX.Y.Z.zip` из раздела
   [Releases](https://github.com/Onlaino/lotro-highlighning-players/releases).
2. Распакуйте архив в
   `Documents\The Lord of the Rings Online\Plugins`.
3. Убедитесь, что существует файл
   `Plugins\HighlightPlayers\HighlightPlayers.plugin`.
4. В LOTRO выполните `/plugins refresh`, откройте менеджер плагинов и загрузите
   `Enemy Highlight`.

После загрузки используйте `/eh` или плавающую кнопку. Обновляя плагин,
замените каталог `HighlightPlayers`, но не удаляйте PluginData.

## Ограничения

LOTRO Lua API не позволяет надёжно отличить PvMP-игрока от NPC и автоматически
определить сторону каждой цели. Поэтому сопоставление выполняется только по
имени выбранной цели.
