# Enemy Highlight

Плагин для The Lord of the Rings Online, позволяющий вручную назначать другим
персонажам статусы `Friend`, `Neutral` и `Enemy`. При выборе сохранённого имени
плагин показывает цветную точку рядом со штатным окном цели.

## Возможности

- три списка: `Friend`, `Neutral` и `Enemy`;
- зелёный, оранжевый и красный индикаторы соответственно;
- карточка игрока с редактируемым именем, статусом и заметкой;
- заполнение имени из текущей цели;
- сохранение данных для всех персонажей одного сервера;
- перемещаемый и блокируемый индикатор;
- управление через окно и команды `/eh`.

## Установка

1. Скопировать каталог `HighlightPlayers` целиком в:
   `Documents\The Lord of the Rings Online\Plugins`.
2. Итоговый путь к манифесту должен быть:
   `Documents\The Lord of the Rings Online\Plugins\HighlightPlayers\HighlightPlayers.plugin`.
3. Войти персонажем в игру.
4. Выполнить `/plugins refresh`.
5. Открыть менеджер плагинов LOTRO и загрузить `Enemy Highlight`.

После успешной загрузки в чате появится:

```text
[HighlightPlayers] Enemy Highlight v0.1.0 loaded. Use /eh to open.
```

## Использование

Выполнить `/eh`, ввести имя, выбрать статус и нажать `Add / update`. Кнопка
`Use target` подставляет имя текущей выбранной цели.

Сохранённые игроки находятся на трёх вкладках. Нажатие на имя открывает
карточку, в которой можно изменить имя, статус, заметку или удалить запись.

Для настройки индикатора выполнить `/eh move`, перетащить появившуюся точку к
штатному имени цели и выполнить `/eh lock`.

## Команды

- `/eh` или `/eh toggle` — открыть или скрыть основное окно;
- `/eh show` — открыть окно;
- `/eh hide` — скрыть окно;
- `/eh move` — разблокировать и показать индикатор для перемещения;
- `/eh lock` — зафиксировать индикатор;
- `/eh add <nickname>` — открыть карточку указанного игрока;
- `/eh add <nickname> <friend|neutral|enemy>` — быстро сохранить статус;
- `/eh probe` — вывести диагностические сведения о текущей цели;
- `/eh help` — показать справку.

## Хранение данных

Данные сохраняются средствами LOTRO через `Turbine.PluginData` с областью
`Turbine.DataScope.Server` и ключом `HighlightPlayers`. Список общий для всех
персонажей пользователя на текущем сервере, включая Свободные народы и
Игроков-монстров. Между разными серверами данные не смешиваются.

Файлы внутри каталога плагина не изменяются.

## Ограничение LOTRO Lua API

`GetTarget()` и `TargetChanged` позволяют получить смену и имя выбранной цели.
Однако PvMP-персонаж может возвращаться клиентом только как `Actor`, у которого
нет `GetAlignment()`. Поэтому плагин не определяет сторону выбранной цели и
сопоставляет сохранённые записи непосредственно по имени.

Из-за этого вручную сохранённая NPC с совпадающим именем технически неотличима
от игрока. Плагин ничего не добавляет автоматически, поэтому пользователь
полностью контролирует список.
